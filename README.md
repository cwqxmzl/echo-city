# 回响之城 · 轮回骰局

文字类肉鸽 × 安科骰子 × 网游文天赋 × 多剧情多结局的单文件网页游戏。

## 玩法简介

被困在一座每轮都会重组的全息网游城市「回响之城」中。每局开局从 3 个随机天赋中选 1 个（D~SSS 七品级，覆盖系统流 / 血统论 / 信息差 / 外挂型等网文金手指），随后选择职业，构筑你的三技能槽，穿戴装备，再踏入轮回。关键抉择由 1d100 安科骰子判定，失败可消耗命运点重掷。死亡不是结束——回响碎片永久累积，提升下一轮初始命运点。

**箱庭式开放世界**：不再是线性章节——开局进入「箱庭地图」，旧日街区 / 中枢塔 / 回响深渊三大区域自由进出，每个区域自带探索点清单（剧情点、可反复刷的巡逻战斗、一次性补给箱）。主线降级为「收集真相碎片 → 解锁回响深渊最终决战」，随时想逛哪逛哪：做支线、刷金币、开宝箱、跨世界搜打撤全随意，通向 4 个结局（含 2 个隐藏结局）。

## 特色系统

- **箱庭开放地图**：旧日街区 / 中枢塔 / 回响深渊 3 大区域自由进出，每个区域有探索点清单（剧情 / 可反复巡逻战斗 / 一次性补给箱），跨区域随时返回，HUD 一键回地图。
- **真相碎片主线**：剧情中收集 3 个真相碎片（灰袍告诫 / 档案真相 / 老猫忠告）解锁「回响深渊」最终决战与 4 结局——不催主线，想干嘛干嘛。
- **天赋构筑**：15 个天赋（D~SSS 七品级），覆盖系统流、血统论、信息差等网文金手指。
- **职业系统**：剑客 / 术师 / 刺客 / 医修 四大职业，各有专属技能池与成长路径；击败敌人获得经验，升级全属性成长并概率领悟新技能。
- **技能系统**：战斗中携带 3 技能 + 法力（MP）资源，普通攻击回蓝；连击、吸血、冻结、护盾、战吼、狂暴等 16+ 技能与 buff/状态效果。
- **背包与装备**：武器 / 防具 / 饰品三槽位，22+ 种道具；药剂、法力药剂、记忆卡等随时可用，装备即时改变属性面板。
- **队伍与强力队友**：6 名强力队友（第二章塔顶救下「老猫」+ 首通海洋/末世/西幻/科幻/无限流世界各一位），队伍上限 3 人，上阵队友在战斗开场与每回合提供被动支援（护盾 / 回蓝 / 开火 / 狂暴 / 减伤等），可在「角色」面板切换上阵与后备。
- **跨世界搜打撤任务板**：浮空群岛、武侠江湖、修仙界、海洋世界、末世废土、西幻大陆、科幻星域、无限轮回 8 个小说世界，三阶段行动（搜索 → 打击 → 撤离）。首通世界获得专属技能、装备或强力队友，重复刷可积累金币与道具。
- **安科骰子**：1d100 判定 + 大成功 / 大失败 / 混沌“？？？？”，命运点重掷。
- **梗与段子**：剧情内置网文 / 游戏 / 程序员梗彩蛋。

## 运行方式

- **直接打开**：用浏览器打开 `index.html` 即可游玩，无需安装、无需联网（纯原生 HTML/CSS/JS，无外部依赖）。
- **在线试玩**：本仓库已开启 GitHub Pages，访问 https://cwqxmzl.github.io/echo-city/ 即可在任意设备（含手机）游玩。
- **本地起服务器（可选）**：`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 内容规模

- 64 事件节点 / 3 大箱庭区域（开放地图，主线为可选「真相碎片」目标）+ 8 个跨世界搜打撤任务
- 15 个天赋（7 品级）+ 4 大职业
- 16+ 技能（含 5 个世界专属技能）
- 22+ 道具 / 装备（武器 · 防具 · 饰品）
- 6 名强力队友（队伍上限 3）
- 15 个敌人（Boss：回响之核 · 审判形态）
- 4 个结局（含 2 个隐藏结局）
- 回响碎片 meta 永久成长（localStorage）

## 校验脚本

- `node _validate.js`：校验事件 / 天赋 / 敌人 / 结局引用完整性与可达性。
- `node _smoke.js`：jsdom 冒烟测试，覆盖职业选择、技能战斗、背包装备、跨世界搜打撤、门控与结局。
