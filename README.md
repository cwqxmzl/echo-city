# 回响之城 · 轮回骰局

文字类肉鸽 × 安科骰子 × 网游文天赋 × 多剧情多结局的单文件网页游戏。

## 玩法简介

被困在一座每轮都会重组的全息网游城市「回响之城」中。每局开局从 3 个随机天赋中选 1 个（D~SSS 七品级，覆盖系统流 / 血统论 / 信息差 / 外挂型等网文金手指），关键抉择由 1d100 安科骰子判定，失败可消耗命运点重掷。死亡不是结束——回响碎片永久累积，提升下一轮初始命运点。三章主线 × 阵营抉择 × NPC 支线，通向 4 个结局（含 2 个隐藏结局）。

## 运行方式

- **直接打开**：用浏览器打开 `index.html` 即可游玩，无需安装、无需联网（纯原生 HTML/CSS/JS，无外部依赖）。
- **在线试玩**：本仓库已开启 GitHub Pages，访问 https://cwqxmzl.github.io/echo-city/ 即可在任意设备（含手机）游玩。
- **本地起服务器（可选）**：`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 内容规模

- 63 个事件节点 / 3 章主线
- 15 个天赋（7 品级）
- 7 个敌人（Boss：回响之核 · 审判形态）
- 4 个结局（含 2 个隐藏结局）
- 回响碎片 meta 永久成长（localStorage）

## 校验脚本

`node _validate.js` 可校验事件 / 天赋 / 敌人 / 结局引用完整性与可达性。
