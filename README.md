# 赢赢赢，骰子中间窜窜窜之文游大冒险

文字类肉鸽 × 安科骰子 × 网游文天赋 × 外挂金手指 × 词条构筑 × 多世界冒险的单文件网页游戏。**爽玩优先**：数值全面上调、机制复合强化、生存限制取消——越轮回越强，越搜越肥，死亡也不掉钱。

## 玩法简介

你在全息网游「回响之城」中苏醒，作为「旅者」在**主线世界与万界冒险**之间自由穿行——这不是被困住，而是一场**盛大冒险**的开始：城市会重建，NPC 会重逢，天赋像老朋友一样一直陪着你。开局从 3 个随机天赋中选 1 个（D~SSS 七品级，覆盖系统流 / 血统论 / 信息差 / 外挂型等网文金手指），随后选择职业，构筑三技能槽，穿戴装备。关键抉择由 1d100 安科骰子判定，失败可消耗命运点重掷。

**多世界冒险 · 不再依赖轮回**：回响之城（主线世界）只是你的初始世界。通过「万界枢纽」，你可以随时进入 **20 个小说 / 知名游戏世界**——每个世界都是敞开的箱庭，有自己的入场剧情、特色玩法与特色随机产物。想打主线打主线，想闯异界闯异界，互不冲突，自由得很。

**外挂（金手指）系统**：每次进入新世界前，可挑 **1-3 个外挂**（签到系统 / 词条篡改 / 看广告变强 / 升级加速 / 无限掉落 / 命运改写 / 肉身成圣 / 修炼加速 / 金色传说 / 存档作弊），整场冒险生效——看广告变强、无限掉落、命运改写……全是网文味儿。

**死亡不是结束**：死亡时金币**全数带进下一轮**（带「存档作弊」外挂再额外多带 50%）；回响碎片永久累积提升初始命运点；词条背包与已装备词条跨周目保留。

- **第二十一轮 · 体验与态度预期（死亡结算 / 动态仁慈 / 选项动作化 / 隐性预告）**：**死亡结算正向化**——死亡不再是「白玩一把」，先弹出「本轮收获结算」：列出本局推进/金币/碎片/解锁内容并明确「全部永久继承」，首次死亡奖励命运点+1，把失败变成蓄力阶段；**动态仁慈系统**——同一判定连续失败 2 次难度悄悄 -5（失败 4 次再 -5）、连续 3 次失败赠一次免费重掷、连续成功 3 次高难度判定难度微 +3，全程不提示保持命运感，新手不卡关老手不无聊；**选项动作化**——街角回响选项从抽象名词改为「动作+语气」：「蹲下身，放轻声音，试着安抚她」「面无表情，抬手直接打散她」「学着她的样子，伸手接过钥匙」，选项即态度；**去道德审判**——驱散类选项中性描述（「干净利落。没必要在循环里浪费时间。」），不评判玩家选择；**微态度反馈**——安抚/共情/驱散后追加内心独白，让玩家感知「选择在影响态度」；**选项隐性预告**——高风险判定（dc≥65）红色预警+⚠ 图标，友善选项暖色，凭直觉判断倾向。
- **第二十轮 · 剧情叙事深度（跨周目态度 / 词条叙事化 / 开场独白）**：**跨周目态度系统**——每个核心 NPC 有隐藏「印象值 + 熟悉度」，跨周目继承；安抚 +10 / 击杀 -15 / 帮助 +20 / 欺骗 -20，行为决定态度，周目只解锁上限；**街角回响（林晚）态度分层**——陌生 → 既视感 → 熟稔 → 宿命四层，选项库随层动态解锁（2 周目新增「叫她的名字」、5 周目新增「告诉她真相」、10 周目新增「替她等」），称呼随层变化（那团回响 → 林晚 → 那个傻姑娘）；**双向反馈**——安抚过则安抚难度 -10 且开场文本变温和，打散过则难度 +15 且她会认出你；**词条叙事化**——全部 10 枚词条新增背景文案（执念/记忆碎片），词条卡斜体展示；**开场轮回者独白**——周目越高独白越沉重（第 2 周「我是不是来过这里？」、第 10 周「要不要改个结局？」），高周目世界观碎片层层浮现。
- **第十八轮 · 面板导航 / 骰子彩蛋 / 战斗倍速 / 成就图鉴**：角色面板新增标签导航（属性/装备/队伍/技能/背包/词条/成就，词条与成就一键直达）；**骰子彩蛋**——连续 3 次大成功触发「天选之人」（白送一枚 A/S 词条 + 命运点）、连续 3 次大失败触发「非酋的慰藉」（下次判定必定大成功 + 回响碎片）；**战斗连打倍速** 1x/2x/3x 切换；**万界图鉴·成就系统**——10 项成就（首战/破界/三界/万界之主/初入轮回/万贯家财/词条收藏家/欧皇附体/非酋见证/烙印初成）达成即领回响碎片与命运点，永久记录；统一品级色板（D~SSS）。
- **UI 交互优化（操作顺滑不打断沉浸）**：键盘快捷键——剧情空格/回车继续、1-9 数字键快速选选项，战斗 Q 普攻 / E 终结技 / 1-3 技能，全局 B 角色面板 / M 枢纽 / Esc 关闭引导（自动避开输入框）；全局按钮状态反馈（悬停提亮 / 按下缩放 / 禁用置灰）；页面切换 280ms 淡入软过渡；骰子判定滚动定格动画（放大命运感）；自动存档「进度已保存」toast（3 秒节流）。

## 运行方式

- **直接打开**：浏览器打开 `index.html` 即可，无需安装、无需联网（纯原生 HTML/CSS/JS，无外部依赖）。
- **在线试玩**：GitHub Pages 已开启，访问 https://cwqxmzl.github.io/echo-city/ 任意设备（含手机）游玩。
