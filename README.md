# 回响之城 · 万界骰局

文字类肉鸽 × 安科骰子 × 网游文天赋 × 外挂金手指 × 词条构筑 × 多世界冒险的单文件网页游戏。

## 玩法简介

被困在一座每轮都会重组的全息网游城市「回响之城」中，作为「穿越者」在**主线世界与万界冒险**之间自由穿行。开局从 3 个随机天赋中选 1 个（D~SSS 七品级，覆盖系统流 / 血统论 / 信息差 / 外挂型等网文金手指），随后选择职业，构筑三技能槽，穿戴装备。关键抉择由 1d100 安科骰子判定，失败可消耗命运点重掷。

**多世界冒险 · 不再依赖轮回**：回响之城（主线世界）只是你的初始世界。通过「万界枢纽」，你可以随时进入 **20 个小说 / 知名游戏世界**——每个世界都是敞开的箱庭，有自己的入场剧情、特色玩法与特色随机产物。想打主线打主线，想闯异界闯异界，互不冲突，自由得很。

**外挂（金手指）系统**：每次进入新世界前，可挑 **1-3 个外挂**（签到系统 / 词条篡改 / 看广告变强 / 升级加速 / 无限掉落 / 命运改写 / 肉身成圣 / 修炼加速 / 金色传说 / 存档作弊），整场冒险生效——看广告变强、无限掉落、命运改写……全是网文味儿。

**死亡不是结束**：回响碎片永久累积，提升下一轮初始命运点；词条背包与已装备词条跨周目保留。

## 特色系统

- **万界枢纽**：主线世界 / 万界冒险 / 世界模拟器 / 角色背包队伍技能 / 存档读档 / 词条工作台 / 自定义剧本 七大入口一屏直达，随时切换。
- **主线世界（回响之城）**：旧日街区 / 中枢塔 / 回响深渊 3 大箱庭区域自由进出，探索点含剧情 / 巡逻战斗 / 补给箱 / 随机际遇；主线降级为「收集 3 个真相碎片 → 回响深渊最终决战」，通向 4 个结局（含 2 个隐藏）。
- **万界冒险 · 世界名录**：20 个小说 / 游戏世界——浮空群岛、武侠江湖、修仙界、海洋世界、末世废土、西幻大陆、科幻星域、无限轮回；致敬知名游戏世界观的「旷野神域」「圣巢深渊」「交界之地」「精灵大陆」「苇名国」「冥界试炼」；小说流派的「国运战场」（国运抽卡，吉凶一念）、「万族战场」「诡秘之都」「洪荒古界」「诸天万界」；以及**「提瓦特大陆」（原神世界 · 元素七国）**——蒙德风起地入场、愚人众先遣队、元素反应技能、玉衡星刻晴入队。每个世界自带入场剧情（intro）+ 特色玩法（special）+ 专属敌人 + 特色随机产物。
  4 个典型世界已点亮**独有可玩机制**：**精灵大陆**·御兽收服（探索中掷骰收服灵兽，战斗开场助战雷光爪）、**苇名国**·忍义潜杀（35% 概率阴影割喉秒杀守卫、免战拿战利品）、**诡秘之都**·理智灵视（每搜一处掉 4 理智，跌破 70 灵视开启——宝物更近、疯狂更近，撤离按理智换灵视情报金）、**圣巢深渊**·魂与回魂（深渊死亡四成金币化作魂坠落，成功撤离魂归原位）。
- **世界剧情线（每个世界都有完整剧情 · 结构合理）**：20 个世界全部配备 **3-4 幕专属剧情**（考据自各自原型——苇名国·只狼、圣巢·空洞骑士、交界之地·艾尔登法环、精灵大陆·宝可梦、旷野神域·塞尔达、冥界试炼·哈迪斯、诡秘之都·诡秘之主、国运战场·国运流、洪荒古界·洪荒流、诸天万界·诸天流、提瓦特·原神……），并升级为**分支因果 + 多结局结构**：① 每个选择累积**剧情倾向**（善/勇/谋/狂），倾向条实时可见；② 中间幕自动追加**因果句**——你的名声与处境会随前序选择变化；③ 结局不再千篇一律，按主要倾向结算出 **4 种专属结局**（善果/勇果/谋果/狂果，各带不同奖励与口碑）；④ 每幕分支选项含**属性检定**（属性×2+1d100 对比 DC，胜负皆有收获）。重游世界可换路线刷不同结局。
- **AI 剧情模式（自由输入 · 动态叙事）**：不再只有固定选项。从枢纽进入「AI 剧情模式」，选一个场景（20 世界 + 自由梦境共 21 个），然后输入你想做的任何事——「行动：……」「说：……」「剧情：……」「看：……」，叙事实时回应。本地生成引擎（完全离线可玩）解析你的动作意图（前进/调查/交谈/战斗/偷窃/搜刮/使用/逃跑等），结合骰子与属性结算收益与风险；它有**记忆**——你偷过的东西会被守卫记住，你救下的人会回来报恩；探索到底可通关本场景（首通 +2 命运点）。想获得真正的无限剧情？在设置里填任意 OpenAI 兼容接口（endpoint + key + 模型），即可接入真实 AI 叙事，请求失败会自动切回本地引擎。
- **外挂（金手指）**：10 个网文风外挂，进入世界前选 1-3 个，整场冒险生效——签到系统（金币）、词条篡改（词条插槽解锁）、看广告变强、升级加速（经验 +50%）、无限掉落（收获率 42%→62%）、命运改写（命运点 +3）、肉身成圣（生命 +30%）、修炼加速（法力 / 回蓝）、金色传说（探索更易掉装备 + 撤离奖励 +20%）、存档作弊（死亡保留一半金币）。
- **词条工作台（红色神器）**：致敬《词条搜打撤》——【词条背包】词条安全储存死亡不掉落、【词条无限】插槽限制解除（携「词条篡改」外挂后）、【词条合成】3 个同品级 + 30 经验合成更高品级、【词条分解】分解 D 级词条每个 +30 经验。D~S 四品 10 词条（丰收 / 警觉 / 洞察 / 坚韧 / 狂暴 / 回响 / 天运 / 噬魂 / 聚宝 / 万般），生效槽默认 3，探索随机掉落永久入库。
- **星铁式队友战斗**：10 名强力队友（含「刻晴 · 玉衡星·雷」——破防后自动补雷切），队伍上限 3。**队友和主角一样战斗**：独立生命 / 能量条，可点按施放【战技】（30 能量）与【终结技】（100 能量）；敌人伤害随机分摊、队友可倒地可复活；能量管理成为战斗策略一环，自动战斗 AI 也会替队友放技能。
- **战斗增强**：主角**回响能量 / 终结技**（剑客八荒裂空斩 / 术师群星陨落 / 刺客终焉影袭 / 医修回响圣域）、**BP 蓄力**（普攻 / 受击积点，技能每蓄力 1 点 +50% 伤害）、**弱点韧性 · 破防总攻**（敌人韧性条打满进入破防 + 眩晕，全队总攻击一波爆发）、**永恒防御 · 一切防御技能自动升金**（致敬《游戏入侵：一切防御技能自动升金》的 SSS 天赋——钢铁之躯受击 -50% / 反甲受击反弹 / 狂徒每回合回血 8% / 无敌致命伤害 40% 免疫）、**天赋共鸣 / 词条联动**（丰收 / 警觉 / 洞察 / 坚韧 / 狂暴 / 回响 / 天运 / 噬魂 / 聚宝等词条在战斗与探索中全面生效）。
- **跨世界箱庭搜索（搜打撤）**：每个世界想搜几处搜几处——每次搜索随机收获（金币 / 药剂 / 世界特色随机产物 / 命运点 / 残响线索），也可能惊动守卫开打或踩中陷阱丢钱丢物。搜索越多警觉越高，每个世界有**探索上限**（低危 8 / 中危 10 / 高危 12 次），搜到极限**强制撤离**，仓皇突围折损三成收益；**残响线索越多撤离奖励越厚**（每条 +4 金币）。首通世界获专属技能 / 装备 / 强力队友，「天赋·过目不忘」额外看破隐藏线索、「任务面板」撤离奖励翻倍、外挂「金色传说」探索更易掉装备。
- **世界模拟器**：搜打撤训练场——不演剧情不选外挂，直接进场刷资源，装备、材料、技能、词条的好出处。
- **随机际遇 / 安科骰子**：街头怪事 / 塔内意外 / 深渊怪谈，1d100 判定 + 大成功 / 大失败 / 混沌“？？？？”，命运点重掷，附赠大量梗段子。
- **存档 / 读档**：1 个自动存档 + 3 个手动档位，随时保存随时回档，手机也能接着玩。
- **自定义剧本（编剧模式）**：参考 MarkdownGame 的多分支文字冒险——标题页点「✍ 自定义剧本」，用 JSON 写「章节 → 选项 → 变量 → 条件分支 → 结局」，导入即玩。

## 运行方式

- **直接打开**：浏览器打开 `index.html` 即可，无需安装、无需联网（纯原生 HTML/CSS/JS，无外部依赖）。
- **在线试玩**：GitHub Pages 已开启，访问 https://cwqxmzl.github.io/echo-city/ 任意设备（含手机）游玩。
- **本地起服务器（可选）**：`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 内容规模

- 64 事件节点 / 3 大箱庭主线区域 + **20 个跨世界箱庭任务世界**（每个 3+ 特色随机产物，含入场剧情与特色玩法）+ 世界模拟器 + 自定义剧本

- 28+ 道具 / 装备（武器 · 防具 · 饰品 · 神之眼 · 圣遗物）
- **10 名强力队友**（队伍上限 3）
