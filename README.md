# 回响之城 · 万界骰局

文字类肉鸽 × 安科骰子 × 网游文天赋 × 多剧情多结局的单文件网页游戏。

## 玩法简介

被困在一座每轮都会重组的全息网游城市「回响之城」中。每局开局从 3 个随机天赋中选 1 个（D~SSS 七品级，覆盖系统流 / 血统论 / 信息差 / 外挂型等网文金手指），随后选择职业，构筑你的三技能槽，穿戴装备，再踏入轮回。关键抉择由 1d100 安科骰子判定，失败可消耗命运点重掷。死亡不是结束——回响碎片永久累积，提升下一轮初始命运点。

**箱庭式开放世界**：不再是线性章节——开局进入「箱庭地图」，旧日街区 / 中枢塔 / 回响深渊三大区域自由进出，每个区域自带探索点清单（剧情点、可反复刷的巡逻战斗、一次性补给箱、随机际遇）。主线降级为「收集真相碎片 → 解锁回响深渊最终决战」，随时想逛哪逛哪：做支线、刷金币、开宝箱、随机际遇、跨世界搜打撤全随意。**主线通关后**可留在当前周目继续逛，或直接进入下一轮觉醒新天赋；**完整存档/读档系统**（1 个自动存档 + 3 个手动存档位）让你随时保存进度、手机也能接着玩，通向 4 个结局（含 2 个隐藏结局）。

## 特色系统

- **箱庭开放地图**：旧日街区 / 中枢塔 / 回响深渊 3 大区域自由进出，每个区域有探索点清单（剧情 / 可反复巡逻战斗 / 一次性补给箱 / 随机际遇），跨区域随时返回，HUD 一键回地图。
- **随机际遇**：每个区域都有「随机际遇」探索点，每次触发从事件池随机抽取一件街头怪事 / 塔内意外 / 深渊怪谈，安科骰子判定，成则金币药剂命运点，败则掉血破财——还附赠大量梗段子。
- **存档 / 读档**：1 个自动存档（进出地图 / 区域自动写入）+ 3 个手动存档位，可随时手动保存、读取、删除；标题页与箱庭地图都可进入存档界面，读档后从存档位置继续。
- **真相碎片主线**：剧情中收集 3 个真相碎片（灰袍告诫 / 档案真相 / 老猫忠告）解锁「回响深渊」最终决战与 4 结局——不催主线，想干嘛干嘛；通关后既可留下继续探索，也可直接进入下一轮。
- **天赋构筑**：15 个天赋（D~SSS 七品级），覆盖系统流、血统论、信息差等网文金手指。
- **职业系统**：剑客 / 术师 / 刺客 / 医修 四大职业，各有专属技能池与成长路径；击败敌人获得经验，升级全属性成长并概率领悟新技能。
- **技能系统**：战斗中携带 3 技能 + 法力（MP）资源，普通攻击回蓝；连击、吸血、冻结、护盾、战吼、狂暴等 16+ 技能与 buff/状态效果。
- **背包与装备**：武器 / 防具 / 饰品三槽位，22+ 种道具；药剂、法力药剂、记忆卡等随时可用，装备即时改变属性面板。
- **队伍与强力队友（星铁式回合制战斗）**：9 名强力队友（第二章塔顶救下「老猫」+ 首通各世界招募，含凝光 · 璃月天权、温蒂 · 风之诗人、荒 · 人族帝君等），队伍上限 3 人。**队友和主角一样战斗**：每名上阵队友拥有独立的生命条与能量条（参考星穹铁道回合制），战斗界面可直接点按施放【战技】（消耗 30 能量）与【终结技】（消耗 100 能量）——老猫的数据修复 / 系统重启（全队治疗+复活）、澜的潮汐之歌 / 海渊之怒、铁壁的能量炮击 / 毁灭齐射、罗兰的圣光斩 / 圣域庇护、灵子的数据流 / 全知协议、无名的终局注视 / 故事终章、凝光的岩晶术 / 琼玑天权、温蒂的千风 / 风神之诗、荒的人皇斩 / 人族永世。敌人攻击不再只盯主角，会**随机分摊到队伍成员**（守望者 / 嘲讽可拉住仇恨）；队友受击掉血并回能，血量归零会**倒地**（其被动支援失效，灵子 / 无名 / 凝光的持续加成一并撤销），治疗 / 复活技能可拉回。每回合自动充能 + 受击回能，能量管理成为战斗策略的一环；自动战斗 AI 也会替队友释放终结技与战技。可在「角色」面板切换上阵与后备。
- **跨世界箱庭探索任务板（搜打撤 V2）**：19 个小说 / 知名游戏世界——浮空群岛、武侠江湖、修仙界、海洋世界、末世废土、西幻大陆、科幻星域、无限轮回；致敬知名游戏世界观的「旷野神域」「圣巢深渊」「交界之地」「精灵大陆」「苇名国」「冥界试炼」；以及小说流派的「国运战场」（国运流，撤离成功额外一次**国运抽卡**：上上签/中吉/小吉/凶/大凶，吉凶一念）、「万族战场」（万族争锋流）、「诡秘之都」（克苏鲁诡秘流）、「洪荒古界」（洪荒流）、「诸天万界」（诸天穿越流）。**每个世界都是一座敞开的箱庭**：进入先由黑塔帮补给满状态（生命/法力全满），然后想搜几处搜几处——每次搜索随机收获（金币 / 药剂 / **世界特色随机产物** / 命运点 / 残响线索），也可能惊动守卫开打，或踩中陷阱丢钱丢物。搜索越多、世界警觉度越高，遭遇与损失概率越大；每个世界有**探索上限**（低危 8 次 / 中危 10 次 / 高危 12 次），搜到极限必须**强制撤离**，仓皇突围会折损三成收益，甚至被世界吞掉部分战利品——**及时抽身**才能把收获稳稳带回家。搜索中锁定的**残响线索**越多，撤离奖励加成越厚（每条 +4 金币），机制环环相扣。首通世界获得专属技能、装备或强力队友，探索中随机收获的**特色产物**（风羽护符 / 龙鳞甲 / 驱魔之剑 / 苇名村正 / 国运玉玺……）也能永久入库；完成越多解锁的世界越离谱。
- **自定义剧本（编剧模式）**：参考 MarkdownGame 的多分支文字冒险——标题页点「✍ 自定义剧本」，用简单 JSON 写「章节 → 选项 → 变量 → 条件分支 → 结局」，导入即玩。人人都能当编剧，写你自己的想法。
- **安科骰子**：1d100 判定 + 大成功 / 大失败 / 混沌“？？？？”，命运点重掷。
- **梗与段子**：剧情内置网文 / 游戏 / 程序员梗彩蛋；世界介绍文案也做了网感化精简。

## 运行方式

- **直接打开**：用浏览器打开 `index.html` 即可游玩，无需安装、无需联网（纯原生 HTML/CSS/JS，无外部依赖）。
- **在线试玩**：本仓库已开启 GitHub Pages，访问 https://cwqxmzl.github.io/echo-city/ 即可在任意设备（含手机）游玩。
- **本地起服务器（可选）**：`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 内容规模

- 64 事件节点 / 3 大箱庭区域（开放地图，主线为可选「真相碎片」目标）+ 19 个跨世界箱庭探索任务（每个世界 3+ 特色随机产物）+ 自定义剧本模式
- 15 个天赋（7 品级）+ 4 大职业
- 21+ 技能（含 10+ 世界专属技能）
- 28+ 道具 / 装备（武器 · 防具 · 饰品）
- 9 名强力队友（队伍上限 3）
- 26 个敌人（Boss：回响之核 · 审判形态）
- 4 个结局（含 2 个隐藏结局）
- 回响碎片 meta 永久成长（localStorage）

## 校验脚本

- `node _validate.js`：校验事件 / 天赋 / 敌人 / 结局引用完整性与可达性。
- `node _smoke.js`：jsdom 冒烟测试，覆盖职业选择、技能战斗、背包装备、跨世界搜打撤、门控与结局。
